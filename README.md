# Commodore Creations

Marketing site for Commodore Creations — in-home holiday decor design and setup.

## Stack

- [Next.js](https://nextjs.org) (App Router, TypeScript)
- [Tailwind CSS v4](https://tailwindcss.com) — theme tokens live in `src/app/globals.css` under `@theme`
- Hosted on [Vercel](https://vercel.com)

## Development

```bash
npm install
npm run dev
```

Open http://localhost:3000.
